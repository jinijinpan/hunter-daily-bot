# 时空猎人·觉醒每日任务助手

这是面向 Windows 微信小游戏窗口的桌面自动化脚本。它不会启动微信或小游戏，不读取游戏进程、内存或网络数据，只使用窗口截图、模板识别和鼠标操作。

## 当前流程

脚本要求小游戏已停在主界面，然后依次执行：

1. 免费找回未使用体力；
2. 进入“福利 > 每日补给”，领取可见的补领/领取奖励；
3. 打开小秘书，按任务图标动态查找并执行已捕获任务；
4. 领取已完成的每日任务奖励；
5. 下滑任务列表并领取可用的活跃度宝箱；
6. 返回主界面，从“选角”切换到下一角色并重复小秘书任务，共处理 3 个角色；
7. 遇到未知页面或未捕获确认框时安全停止并保存截图。

已经实现完整适配器：

- 无尽塔：有“快速挑战”时优先速通；按钮不可用时按捕获链路开始挑战、确认难度、等待自动战斗、关闭通关奖励并退出结算；
- 猎魔战场：页面提供“快速通关”时优先执行；旧页面则开始挑战，失败时速通上一关并领取奖励；
- 资源补给：选择魔晶补给并速通一次；
- 深渊挑战：连续单人挑战，逐次处理胜利、翻牌和奖励；出现“体力获取”弹窗后确认体力不足并返回安全区；
- 魔物入侵：循环执行“挑战 > 快速匹配”，处理胜负和奖励，最多完成每日 5 次；
- 猎人联赛：按已勾选的“跳过战斗”设置完成 10 场匹配，并领取可用的每日奖励和挑战奖励；
- 无限秘境：处理段位结算，依次完成 1-1、1-2、1-3，并从最终关卡返回安全区。

脚本从当前角色开始，完成并领取已适配的小秘书任务后返回主界面，再依次切换到另外两个角色；第三个角色处理完毕后也会返回主界面再结束。换角页通过绿色“在线”标记识别当前角色，因此无论开始时使用哪个角色，都只会处理 3 个不同角色；角色数量可通过 `config.json` 的 `character_cycle_count` 在 1–3 之间调整。已经完成且领取过的任务会根据 `1/1` 或 `3/3` 进度跳过，不会因按钮恢复为蓝色“前往”而重复执行。

脚本不会主动执行：消耗150体力、天梯赛、宠物岛和交易行。若这些任务已经由人工完成，统一领奖步骤仍会领取其奖励。深渊挑战会持续消耗每次约 50 体力，直到弹出体力不足页面；如不希望执行，可从 `config.json` 的 `captured_task_adapters` 中删除 `abyss`。猎人联赛依赖游戏内“跳过战斗”保持勾选，脚本不会切换该复选框。

## 安装

建议使用 Python 3.11。在 PowerShell 中执行：

```powershell
cd C:\分析\hunter-daily-bot
python -m pip install --user -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python bot.py prepare
```

页面和任务图标模板已经生成在 `assets/`。修改 `references/` 或 `config.json` 后，需要重新运行 `python bot.py prepare`。

## 使用

先在微信中打开小游戏并停在主界面。脚本会分别识别微信标题栏和游戏画布，可适配与参考截图比例不同的窗口；正式运行期间仍不要让其他窗口遮挡游戏。

只检查当前页面，不点击（检查时会把游戏窗口置前）：

```powershell
python bot.py inspect
```

输出计划，不执行点击：

```powershell
python bot.py run
```

允许真实点击、拖动和任务操作：

```powershell
python bot.py run --execute
```

如果上次运行已经完成体力和补给、但在返回主界面后停止，可直接从小秘书阶段续跑。脚本也能从深渊入口、胜利结算、翻牌、再次挑战或体力耗尽页面直接续跑：

```powershell
python bot.py run --execute --resume
```

每次运行的日志和安全停止截图保存在 `runs/<时间>/`。建议首次真实运行时观察整个过程；如果游戏更新了界面，先停止并重新捕获，不要降低识别阈值强行运行。

## 捕获新任务

运行：

```powershell
cd C:\分析\hunter-daily-bot
python recorder.py
```

也可以双击 `start-recorder.cmd`。终端显示“捕获已开始”后切回游戏，完成一个任务并返回小秘书，然后按 `F8` 停止。

捕获器只在标题含“时空猎人”的目标窗口位于前台时工作，只记录左键点击、按住拖动、相对坐标和游戏客户区截图，不记录键盘输入或其他窗口。结果保存在 `recordings/<时间>/`：

- `timeline.jsonl`：点击、拖动和页面变化时间线；
- `action-*-before.png`、`action-*-release.png`、`action-*-after.png`：操作前后截图；
- `frame-*.png`：无鼠标操作时的页面变化关键帧；
- `run.log`：捕获日志。

录制完成后可压缩截图；默认使用 128 色 PNG，保留时间线引用和画面尺寸，并且只替换确实更小的文件：

```powershell
python compress_recordings.py
```

未实现任务需要从小秘书点击“前往”开始，完整捕获进入、匹配/开始、战斗或速通、胜负结算、奖励和返回小秘书的全过程。

## 验证

运行离线测试：

```powershell
python -m unittest discover -s tests -v
```

测试覆盖坐标缩放、页面模板、任务重排、活跃宝箱状态、无尽塔/猎魔计算阶段防误点，以及四个任务状态机的操作顺序。
